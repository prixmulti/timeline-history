Visual timelines with stories from arkiv.dk: import, Studio editor, and front-end display.

== Description ==

Historical Timeline helps local archives and history groups show an interactive timeline on a WordPress site.

* Import posts from arkiv.dk with preview and year filters
* Edit stories in Studio with live preview
* Shortcode and Gutenberg block
* Per-timeline styling or follow the active theme

Danish admin UI and strings use the `prix-historical-timeline` text domain.

Historical Timeline is developed by Palle Rix (prix.dk) and is not affiliated with or endorsed by arkiv.dk.

== Installation ==

1. Upload the plugin folder or zip via *Plugins → Add New → Upload Plugin* in WordPress.
2. Activate *Historical Timeline*.
3. Open *Historical Timeline → Import from arkiv.dk* or *Studio*.

== Frequently Asked Questions ==

= How do I show a timeline on a page? =

In Studio: select the timeline, copy the shortcode, and paste it on a page. Or add the *Historical Timeline* block in the block editor.

= Do images need to be hosted on my server? =

Imports from arkiv.dk usually link to images on arkiv.dk. You can also add images from the Media Library in Studio.
